# STEP20-2 - 인덱싱 성능 최적화 보고서

## 📋 개요

데이터베이스 인덱스 최적화를 통한 성능 개선 보고서입니다.

**테스트 환경**:
- 부하 테스트 도구: K6
- 모니터링: Grafana + InfluxDB
- 테스트 스크립트: [concert-reservation-test.js](https://github.com/hanghae99-backend/2-SERVICE/blob/STEP20/performance-test/concert-reservation-test.js)

**테스트 제약사항**:
- 조회 데이터량이 상대적으로 적음 (초기 개발 단계)
- 조회 API 종류가 제한적임
- 대규모 데이터에서의 인덱스 효과는 더 클 것으로 예상

## 🔍 결론

### 성과
- ✅ **최대 응답시간 대폭 개선**: 6.28s → 131.36ms (97.9% 개선)
- ✅ **전반적 안정성 향상**: 극단적인 지연 사라짐
- ✅ **쿼리 성능 개선**: 테이블 스캔 → 인덱스 스캔으로 성능 향상
- ✅ **DB 부하 감소**: CPU 사용률 현저히 감소

### 개선점
- 인덱싱 미적용시 발생하는 극단적인 지연 문제 해결
- 복합 인덱스 설계 및 적용으로 쿼리 패턴 최적화
- 전체적인 시스템 안정성 향상

### 테스트 한계
- **데이터량 제약**: 현재 조회 데이터가 상대적으로 적어 인덱스 효과가 제한적
- **API 다양성 부족**: 조회 API 종류가 제한적이어서 다양한 시나리오 테스트 미흡
- **대규모 데이터에서 더 큰 효과 예상**: 실제 운영 환경에서는 더 큰 성능 개선 기대

### 주목할 점
- 최대 응답시간의 극단적 개선이 가장 중요한 성과
- 인덱스가 없을 때 발생하는 6초 대의 지연은 실제 서비스에서 치명적
